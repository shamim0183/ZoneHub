==================================================================
              ZoneHub - Advanced Management Tools                
==================================================================

This folder contains granular utility scripts for power users & IT:

  * Make-IP-Permanent.bat       - Lock current LAN IP so router never changes it
  * Revert-To-Automatic-IP.bat  - Revert network card back to DHCP
  * Enable-AutoStart-NoLogin.bat- Run server even before any user logs in (Windows Task)
  * Disable-AutoStart-NoLogin.bat- Remove Windows boot task
  * Start-Online-Tunnel.bat     - Manually start Cloudflare online tunnel
  * Set-Custom-Online-Url.bat   - Save custom global URL
  * Connect-ZoneHub-Client.bat  - Client connection helper
  * Restart-Server.bat          - Quick restart server
  * Build.bat                   - Recompile server.exe & ZoneHubBubble.exe

NOTE: For normal users, everything is automatically handled by:
  -> Setup-ZoneHub.bat (In root folder)
  -> Browser Admin Modal (Click 'Admin' in top navigation bar)
