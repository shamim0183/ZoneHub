📲 Install App on Your Device

এক ক্লিকে আপনার ফোন বা কম্পিউটারে অ্যাপ হিসেবে ইনস্টল করুন। বারবার কোনো বড় লিংক টাইপ বা মনে রাখতে হবে না!

1
Safari ব্রাউজারের নিচে বা উপরে থাকা Share (শেয়ার) বাটনে ( ⎋ / [↑] ) চাপুন।
2
মেনুটি একটু নিচে স্ক্রল করে "Add to Home Screen" (হোম স্ক্রিনে যোগ করুন) অপশনে চাপুন।
3
উপরে ডানের "Add" বাটনে চাপুন।
✨ সাথে সাথে আপনার iPhone-এর হোম স্ক্রিনে ZoneHub-এর সুন্দর অ্যাপ আইকন যুক্ত হয়ে যাবে!
1
Chrome ব্রাউজারের উপরে ডানদিকের ৩-ডট মেনু [ ⋮ ] চাপুন।
2
"Install app" অথবা "Add to Home screen" অপশনটিতে ক্লিক করুন।
3
পপ-আপে "Install" চাপুন।
⚡ পরের বার কোনো ব্রাউজার অ্যাড্রেস বার ছাড়াই ফুল-স্ক্রিন দেশি অ্যাপের মতো ওপেন হবে!
1
Chrome / Edge (Mac): অ্যাড্রেস বারের ডানে থাকা Install Icon ( ⊕ বা 💻 ) চাপুন এবং "Install" বাটনে ক্লিক করুন। ZoneHub সরাসরি আপনার Mac Launchpad ও Applications ফোল্ডারে যুক্ত হবে।
2
Safari (macOS Sonoma / Sequoia): উপরে মেনু থেকে File চাপুন > "Add to Dock" সিলেক্ট করুন। সাথে সাথে আপনার Mac Dock-এ ZoneHub আইকন চলে আসবে!
3
Always-On-Top Mini Dock: উপরে থাকা "📌 Mini Dock" বাটনে চাপলেই Premiere, Final Cut বা Finder-এর উপর ভাসমান ফ্ল্যাটিং পপ-আউট উইন্ডো ওপেন হবে!
🍎 Mac ব্যবহারকারীদের কোনো .exe ডাউনলোড করতে হয় না! এটি সম্পূর্ণ নেটিভ Mac অ্যাপের মতো কাজ করবে।
1
Chrome বা Edge ব্রাউজারের অ্যাড্রেস বারের ডানে থাকা Install Icon ( ⊕ বা 💻 ) চাপুন।
2
"Install" বাটনে ক্লিক করলেই ইনস্টল সম্পন্ন হবে।
🚀 আপনার Windows টাস্কবার ও ডেস্কটপে আইকন তৈরি হবে, ১-ক্লিকেই সরাসরি চালু হবে!
⚡ ZoneHub Storage & Download Guide
1
ডুপ্লিকেট মেমোরি ছাড়াই হোস্ট পিসির ফাইল শেয়ার: যেহেতু ZoneHub আপনার এই পিসিতেই চলছে, তাই ব্রাউজার দিয়ে বড় ভিডিও আপলোড করার কোনো প্রয়োজন নেই!
2
সরাসরি Move / Cut-Paste করুন: আপনার পিসির যেকোনো ভিডিও বা ফাইল সরাসরি Windows File Explorer দিয়ে Videos\, Pictures\ বা যেকোনো ফোল্ডারে পেস্ট করে দিন। ZoneHub এক সেকেন্ডেই তা লাইভ ডিটেক্ট করবে—জিরো বাইট অতিরিক্ত মেমোরি নষ্ট হবে!
3
অন্য ড্রাইভের ফোল্ডার লিংক করা (mklink): D: বা E: ড্রাইভের বড় ফোল্ডার কোনো কপি ছাড়াই দেখাতে কমান্ড প্রম্পটে চালান: mklink /J "...\Screen Recordings\MyFolder" "D:\MyFolder"।
💡 অন্যান্য কর্মচারীরা যখন আপলোড করে, তাদের ফাইলগুলো অবশ্যই আপনার সার্ভারে সেভ হবে যাতে পুরো টিম দেখতে পারে।
1
ব্রাউজারে ফোল্ডার নির্বাচন সক্রিয় করুন: স্বয়ংক্রিয়ভাবে Downloads ফোল্ডারে না গিয়ে কোথায় সেভ হবে তা নিজে পছন্দ করতে চান?
2
Chrome / Edge-এ সেট করুন: ব্রাউজার সেটিংস > Downloads-এ যান। সেখানে "Ask where to save each file before downloading" (বা প্রতিবার কোথায় সেভ হবে জানতে চাওয়া হোক) অন করে দিন।
3
এখন যেকোনো ফাইল, ছবি, ফোল্ডার জিপ বা অ্যালবাম জিপ ডাউনলোড করলেই Windows আপনাকে ফোল্ডার (D: ড্রাইভ, ডেস্কটপ, পেনড্রাইভ ইত্যাদি) বেছে নেওয়ার অপশন দেবে!
📥 একবার এই সেটিং অন করলে যেকোনো ডাউনলোডের সময় Windows-এর চেনা "Save As" ডায়ালগ বক্স ওপেন হবে।
